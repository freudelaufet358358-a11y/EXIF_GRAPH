# EXIF Graph

大量の写真の EXIF を読み込んで、**どの焦点距離・絞り・シャッター速度・ISO で撮っているか**をまとめて分析する Web アプリです。

公開ページ: https://freudelaufet358358-a11y.github.io/EXIF_GRAPH/

## 特徴

- **写真はアップロードされません。** 解析はすべてブラウザの中で行います。
- **何千枚でも OK。** 各ファイルの先頭のメタデータ部分だけを読むので、RAW でも高速です（8 並列で読み込み、途中経過もその場で表示）。
- フォルダごとドラッグ＆ドロップ、フォルダ選択、ファイル選択に対応。あとから写真を追加すると同じファイルは自動で重複排除します。
- 対応形式: JPEG / HEIC / HEIF / AVIF / TIFF / PNG / WebP / DNG / CR2 / CR3 / NEF / NRW / ARW / SR2 / ORF / RW2 / RAF / PEF / SRW / 3FR / ERF / IIQ など

## 分析できること

| グラフ | 内容 |
|---|---|
| 焦点距離 | 値ごと / レンジ別（超広角〜超望遠）。35mm 換算と実焦点距離を切り替え可能 |
| 絞り（F 値） | 値ごと / 1 段ごと |
| シャッター速度 | 1/3 段 / 1 段ごと（1/125, 1/250 のような一般的な表記にまとめます） |
| ISO 感度 | 1/3 段 / 1 段ごと |
| 焦点距離 × 絞り | どの画角でどこまで絞っているかのヒートマップ |
| カメラ / レンズ | 使用回数のランキング（クリックで絞り込み） |
| 撮影時期 / 時間帯 | 日・月・年別の枚数、何時ごろ撮っているか |
| 撮影モード | 絞り優先・マニュアルなどの内訳 |

上部のフィルタ（期間・カメラ・レンズ）はすべてのグラフに同時に効きます。各グラフは「表」表示にも切り替えられ、表示中のデータは CSV に書き出せます。

35mm 換算焦点距離が記録されていない写真は、同じカメラで撮った他の写真の換算比から推定します（推定した枚数はグラフの下に表示）。

## 開発

ビルド不要の静的サイトです（`site/` 以下）。

```sh
npm test          # EXIF パーサーと集計ロジックのテスト（Node.js 20 以上）
npm run serve     # http://localhost:8000 でプレビュー
```

- `site/js/exif.js` — 依存ライブラリなしの EXIF リーダー（JPEG / TIFF 系 RAW / HEIF / CR3 / RAF / PNG / WebP）
- `site/js/stats.js` — 段数ごとのビン分けや集計
- `site/js/charts.js` — SVG / HTML の小さなチャート部品
- `site/js/app.js` — 画面とファイル読み込み

## デプロイ

`.github/workflows/pages.yml` がすべての push でテストを実行し、`main` ブランチへの push（または手動実行）で `site/` を GitHub Pages に公開します（リポジトリの Settings → Pages → Source は「GitHub Actions」）。

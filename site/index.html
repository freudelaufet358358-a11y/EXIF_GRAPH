焦点距離の基準

EXIF Graph — 写真のファイル先頭のメタデータだけを読み取り、ブラウザ内で集計します。対応形式: JPEG / HEIC / HEIF / AVIF / TIFF / PNG / WebP / DNG / CR2 / CR3 / NEF / NRW / ARW / SR2 / ORF / RW2 / RAF / PEF / SRW / 3FR / ERF / IIQ など。
